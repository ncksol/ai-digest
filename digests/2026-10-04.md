## Uber uses an MCP gateway to connect agents to internal services

A technical account of Uber's agent infrastructure described a central MCP gateway that routes calls, applies permissions and translates requests to internal APIs. The post said Uber uses AutoCrawler to generate tools from API definitions and Omni MCP to discover and load only the tool schemas an agent needs, rather than placing more than 5,000 tools into its context at once.

## Coding-agent abstractions can narrow the design space

Software developer Matt Pocock argued that well-designed abstractions and strict lint rules reduce the number of poor implementation choices available to coding agents. He said they can also reduce code volume and token use, while agents make it cheaper to undo an abstraction that does not work.

## Levie says agent adoption remains concentrated in coding

Box chief executive Aaron Levie described agent adoption as concentrated in coding and related work, with a range from one-to-one assistance to parallel background agents. He said broader knowledge-work deployment requires redesigned workflows, connected data, decision accountability, compliance and security rather than simply adding a chat interface.

## Rauch sees security shifting toward verification and prioritisation

Vercel chief executive Guillermo Rauch argued that software security will increasingly involve verifying code properties and deciding where to spend defensive effort against AI-enabled attackers. He said small companies will face greater trust demands but could also build security products for an increasingly centralised software ecosystem.
