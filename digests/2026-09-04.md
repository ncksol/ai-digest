## Manager Loop divides long agent runs into phases

Matt Shumer described a Manager Loop that uses one Astra agent to plan and supervise a second implementation agent. The manager divides a long task into phases, assigns each phase separately and waits for completion before advancing, which Shumer said reduced the tendency for long runs to stall in minor details.
