## Karpathy says a single Claude Code prompt can build a thumbnail extension

Developer Pondorasti released Honest Thumbnails, a Chrome extension built with Claude that replaces YouTube's uploaded thumbnails with still frames from the video, after learning from Karpathy's HackerTube project that YouTube's CDN serves frames from points within each video. Replying, Andrej Karpathy praised the extension and noted that the same result can be had by asking Claude Code to create and deploy a browser extension showing thumbnails from halfway through the video, with a toggle between the two versions.

## GPT-6 Astra edits Qwen weights directly to improve maths

Researchers report asking GPT-6 Astra to edit the weights of Qwen3.5-0.8B to improve its maths performance. The model changed only 0.016% of the weights, without gradients or training, fixing reasoning loops and improving maths scores up to sixfold and instruction following threefold. The authors call the technique Weight-Space Programming.
