## Karpathy argues agents make deep framework abstractions worth tearing down

Chris McCormick described writing his model code as a single compilable forward_backward function, dropping autograd and torch.nn abstractions in favour of raw matrices and hand-written backward math, with Claude writing that backward path for the 24-layer nanochat architecture. Andrej Karpathy replied that tearing down such abstractions is increasingly appealing now that agents can handle the math, drudgery and verification, adding that many of those abstractions were built for a world constrained by finite intelligence and attention.
