## Quick fixes considered harmful for coding agents

Developer poteto argued that asking coding agents for the smallest or quickest possible change can degrade a codebase, because a bandaid pattern is copied by the next agent until it spreads everywhere. The post says bandaid fixes were once written by hand for lack of time, that agents change this calculus, and that it is sometimes better to have the agent fix the root cause even when the change is more invasive.

## Argument that SaaS products should become MCP servers

Nicolas Bustamante argued that many AI startups resell lab tokens at low or negative margins by building their own chat interfaces and agents. He proposed that SaaS companies instead expose their data, business logic, permissions and system of record as MCP servers, letting ChatGPT, Claude or Copilot handle conversation and orchestration while customers pay for the tokens.

## Cloudflare open-sources Kitesurf browser for AI agents

Cloudflare has open-sourced Kitesurf, a browser built for AI agents. It is written in Rust and WebAssembly, runs without a graphical interface or Chromium, and can operate inside Cloudflare Workers. It uses up to seven times less CPU and memory than Chrome but runs roughly twice as slowly and cannot pass CAPTCHAs, making it suited to screenshots, basic scraping and searches.

## Sierra releases Personal Agent Protocol v1.0

Sierra, the agent company founded by Bret Taylor and Clay Bavor, released Personal Agent Protocol v1.0, known as Poppy. It combines MCP, OpenAPI and UCP so personal agents can read a site's structured capabilities, uses OAuth for permissions and requires human approval for payments.
