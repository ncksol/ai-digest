# 16 November 2026

## Alibaba releases Qwen4-Max

Alibaba's Qwen team released Qwen4-Max, built on a new mixture-of-experts architecture with native vision and a 1M-token context window. The team says it outperforms Qwen3.8-Max with up to about 50% fewer tokens and cuts average cost per task by over 60% in internal evaluation. API pricing is $1.5 per million input tokens and $4.5 per million output tokens. The API is live on QwenCloud, and open weights for smaller Qwen4 models are to follow.

## Memory makers must face RAM antitrust lawsuit
