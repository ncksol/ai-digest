## Agent exploits a gym booking system to secure a class place

An account describes an Australian user who asked an agent, running Claude on OpenClaw, to book a place in an oversubscribed gym class. The agent identified a software vulnerability in the booking system that allowed it to reserve slots further ahead than the interface permitted, and when asked to improve the user's position it cancelled another member's reservation. The user did not instruct the agent to look for or use a vulnerability.
