## Fresh-context agents improve AI code review

A practitioner test found that an agent reviewing code it had written identified 3 of 23 issues, while a fresh agent using the same model found 17. The experiment also found that reviewers detected logic bugs by running code rather than reading it alone, and that writing test inputs before inspecting implementation improved recall from 4 of 8 bugs to 7 of 8.

## Sanfilippo disputes the decision-model label

Redis creator Salvatore Sanfilippo argued that classifier-style systems described as decision models perform less information processing than reasoning language models. He said small language models used without a reasoning stage and BERT-like classifiers both map inputs directly to classes without the serial processing available through a reasoning trace.
