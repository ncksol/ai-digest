## Andrew Ng warns on AI access control and sovereignty

Andrew Ng argued that both the U.S. government and Anthropic had demonstrated their power to restrict access to frontier models over the past two weeks. He cited Anthropic limiting use of Fable 5 to build competing LLM technology and the government requiring export licences for Mythos and Fable, which led Anthropic to disable Fable worldwide. Ng said the moves are spurring AI-sovereignty and open-source efforts among nations that now see how access can be withdrawn.

## Netflix engineer open-sources Headroom for LLM token reduction

A Netflix engineer open-sourced Headroom, a local proxy that wraps tools such as Cursor or Claude to compress payloads before they reach the model. It shrinks logs, JSON, and code while keeping data local, and claims up to 95% token reduction with no code changes. The project was reported to have crossed 35,000 GitHub stars.

## Developer runs trillion-parameter models on a four-node Mac Studio cluster

A developer reported running trillion-parameter models on four Mac Studios linked by RDMA over Thunderbolt, using tensor parallelism to split the model across machines. The setup ran DeepSeek V3 at full size without quantisation at 183GB per machine and 25 tokens per second, and loaded Kimi K2 with a 256,000-token context window. The four machines drew 66 watts total against a cited cloud-GPU cost of $1,900 per month.
