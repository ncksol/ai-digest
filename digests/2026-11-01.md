A widely shared post states that Anthropic will begin watermarking text written by Claude worldwide from Tuesday, with detection tools made available to regulators, journalists and large enterprises but not to the users who generated the text. The post contrasts this with OpenAI, which it says applies such watermarking only in the EU.

## LeCun and Balestriero paper addresses the Platonic Representation Hypothesis with JEPAs

A paper by Yann LeCun and Randall Balestriero shows mathematically that, under certain conditions, two separately trained JEPAs, one on images and one on text descriptions, learn essentially the same representation without paired image-text data. The approach reaches comparable image-text alignment with 42 times fewer training samples than next-token prediction, and a 109M-parameter text JEPA outperforms LLMs of up to 72B parameters on cross-modal alignment benchmarks.

## Google open-sources Elephant-Goldfish planning plugin for coding agents

Google has open-sourced the Elephant-Goldfish Model, a plugin used internally to make coding agents settle a plan before writing code. One long-lived session drafts the design document, while fresh agents with no chat history review it to surface unstated assumptions; the user then approves the plan before implementation. It works with Claude Code and Codex.
