## Patrick Collison sketches a missing LLM workflow tool

Stripe co-founder Patrick Collison described the kind of LLM workflow tool he wants and cannot find: a system that can manage a set of Markdown-style input files and other context, support real-time collaboration with snapshot or VCS-style versioning, and let users create and manage inference workflows on top of that shared context.

## Gwern flags narrow frame in agentic LLM research runs

Gwern argued that most current agentic LLM research runs stay within a narrow frame and only try minor variations on well-trodden ground such as tweaking a decoder Transformer, and suggested prompting models to propose more unusual designs, including pure-MLP variants, given how much they already know about the literature.
