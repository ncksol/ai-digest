## Explainer covers why KV caches skip the query vector

A widely shared technical thread walks through why a KV cache stores key and value vectors but never the query vector, framed as a common LLM interview question. It explains that because LLMs are autoregressive and predict each token from all previous tokens, the cached keys and values are reused across steps while a fresh query is computed each time.
